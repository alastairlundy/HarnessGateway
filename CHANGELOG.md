# Changelog

All notable changes to HarnessGateway are documented in this file.

The format follows [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/) and version headings follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html) in release-tag form (`v0.1.0`). The heading matches the git tag the publish workflow asserts against the project's pinned version. Nothing enforces this format automatically. Each release's notes begin as the generated changelog draft on the draft release, and the maintainer's curation writes both the GitHub release page and the matching entry below in a single pass, so the two surfaces cannot drift apart.
